### 1.4 SymPy 服务硬化（本轮）

- **解析沙箱**：`safe_sympify` 使用 `global_dict` 白名单，拒绝 `__`、属性访问、容器语法、保留字；长度上限 512 字符；`check_expression_budget` 限制 AST 节点数 ≤2000、幂次 ≤60。
- **执行超时**：所有计算在独立子进程中执行（`run_isolated`），默认 12s（`SYMPY_COMPUTE_TIMEOUT_SECONDS`），超时 `terminate()` 强杀并返回 `504 + TIMEOUT`。子进程而非线程，因为 CPU 计算无法从外部中断线程。
- **内部令牌**：计算端点挂在带 `Depends(verify_internal_token)` 的 router 上，要求 `X-Internal-Token`；`/` 与 `/health` 保持公开供探活。未配置令牌时不启用（本地开发/自检）。
- **结构化错误码 + 真实状态码**：`PARSE_ERROR→400`、`UNEVALUATED→422`、`LIMIT_DOES_NOT_EXIST→422`、`TIMEOUT→504`、`INTERNAL_ERROR→500`（此前一律 HTTP 200 + `success:false`）。
- **客户端**：`common/utils/sympy-client.util.ts` 统一注入令牌、超时（`SYMPY_TIMEOUT_MS`，默认 20s，略大于服务端预算以便拿到结构化 504）；`SympyService`、`solver.agent.ts`、`local-computation.service.ts` 三处调用点均已接入，并能从 4xx/5xx 错误体里恢复 `limit_does_not_exist` 之类的**结论性**信息。
- **端口收敛**：compose 中 sympy 仅绑定 `127.0.0.1:8000`。
- 自检：`sympy-service/selfcheck.py` 25 项（新增超时、令牌、错误码用例）。

### 2.9 Verifier 自校验（本轮）

- 新增 `solution-verification.service.ts`：
  - 求导：精确多项式符号通道 + 中心差分数值通道（相对误差 ≤1e-4）；
  - 积分：对结果求导回代（微积分基本定理）+ 定积分 Simpson 交叉验证；
  - 方程：解代回原方程查残差（支持 `±2`、`1/2`、`sqrt(2)` 等写法）;
  - 极限：双侧趋近序列（含“不存在”“±∞”判定）。
  - 证据不足时明确返回“未验证”，**绝不默认通过**。
- 已接入 `AgentsService.solveProblem`，结果写入 `MultiAgentResult.verificationResults`（`verifier:*`），前端可据此显示“已通过数值/符号验证”徽章。
- 独立测试集 `solution-verification.service.spec.ts` 20 个用例。
