### 环境坑（本机）
- `bash` 会转发到 `wsl.exe`，而 wsl.exe 在安全策略黑名单里 → **`bash -n` 不可用**。
  替代方案：`scripts/sh-structure-check.cjs`（结构断言）+ `npm run check:sh`。
- 通过 Bash 工具执行内联 node 脚本时，**反引号会破坏 shell 解析**；复杂脚本一律写成
  `.cjs` 文件再执行，不要塞进 `-e`。
